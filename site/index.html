DSH-X
DeepSeek Harness 离线启动器

装上就能用，
不需要联网。

DSH-X 把 DeepSeek Harness 的运行时、本体、插件与 WebView2 全部打进一个安装包。 装完直接对话 —— 不用登录、不用填 API Key、不用等下载。

下载 Windows 版 看看有什么

Windows 10 1803+ / 11 · 约 316 MB · 免登录使用内置免费模型

功能

  • 全程离线 —— 自带 Node 运行时、dsh 本体、内置插件和 pnpm 缓存，装机器一个请求都不发出去。
  • 插上就能聊 —— 内置免费模型插件，装完直接对话，不登录、不填 Key。
  • 内置 WebView2 运行时 —— 界面装进启动器自己的窗口，不依赖系统装过什么，也不经过浏览器进程。
  • 环境隔离 —— 每个 profile 可选独立家目录，版本、插件、配置与会话互不串扰。
  • 整合包 —— 一次装好一批插件和它们的配置，内置一份推荐包，也可从本地 .dspack 装。
  • 数据在你手里 —— 配置在 %APPDATA%\DSH，会话在 ~/.dsh；卸载只删程序，这些一律保留。

安装时可选「仅为我安装」（默认，免 UAC）或「为所有用户安装」（装到 Program Files，需要管理员）。 程序没有代码签名，SmartScreen 提示「未知发布者」是正常的 —— 点「仍要运行」。

常见问题

要自己准备 Node 或 dsh 吗？
不用。安装包里带着运行时与 dsh 本体。

能装到别的盘吗？
可以，安装向导里有目录选择页。

卸载会删掉聊天记录吗？
不会。卸载只删程序自己装的东西，配置与会话留在用户目录里，重装后接着用。

为什么装了 WebView2？
旧版 Windows 或精简系统上未必预装它，缺了界面就只能退回系统浏览器。带一份固定版本，到哪都一样。
